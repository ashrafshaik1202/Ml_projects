# Uber Fare Prediction

## Overview
This project predicts Uber fares based on trip distance using Simple Linear Regression.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle

## Model
Simple Linear Regression

## Performance
- MAE : 2.0877
- RMSE : 3.2236
- R² : 0.8749

## Run

streamlit run fare.py
